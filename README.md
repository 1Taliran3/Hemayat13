# حمایت ۱۳ — Hemayat 13

نمونه‌کار وب فارسی و راست‌چین با React، Vite و React Router. این پروژه برای نمایش مهارت طراحی و پیاده‌سازی رابط کاربری آماده شده است.

## اجرا در ویندوز PowerShell

نیازمند Node.js نسخه ۲۰.۱۹ یا جدیدتر و npm:

```powershell
npm.cmd install
npm.cmd run lint
npm.cmd run build
npm.cmd run dev
```

## صفحات

- `/` صفحه اصلی و معرفی تجربه حمایت ۱۳
- `/project` مطالعه موردی و معرفی پروژه برای رزومه
- `/login` و `/register` صفحات ورود و ثبت‌نام
- `/donate` فرم ثبت درخواست (بدون پرداخت واقعی)
- `/dashboard` داشبورد و سوابق درخواست‌ها

## فناوری‌ها

React، React Router، Vite، CSS، GitHub و Vercel. در پوشه `backend` نیز API مبتنی بر Node.js و Express و طرح پایگاه داده PostgreSQL/Supabase قرار دارد.

## محدودیت‌های نسخه نمونه‌کار

- اعداد و آمار کارت کمپین نمونه و محلی هستند و از دیتابیس خوانده نمی‌شوند.
- ثبت درخواست حمایت، در صورت پیکربندی صحیح API و دیتابیس، فقط درخواست را ثبت می‌کند؛ پرداخت بانکی انجام نمی‌شود.
- هیچ درگاه پرداخت واقعی در این پروژه فعال نیست.
- وجود کد API در مخزن یا پاسخ‌گویی endpoint ریشه به‌تنهایی به معنی اتصال عملیاتی و آزموده‌شده همه مسیرها به دیتابیس نیست.
- پیش از معرفی قابلیت ورود، ثبت‌نام یا داشبورد به‌عنوان قابلیت عملیاتی، باید سرویس بک‌اند، متغیرهای محیطی، دیتابیس و مسیرهای API در محیط واقعی جداگانه آزمایش شوند.

## معرفی رزومه‌ای

صفحه `/project` برای معرفی هدف پروژه، فناوری‌ها، قابلیت‌های رابط کاربری و مرزهای نسخه فعلی اضافه شده است.
